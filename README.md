## GeradorSenha

Um gerador de senhas simples e eficiente desenvolvido para criar senhas seguras e personalizadas.

## 🔥 Funcionalidades

Geração de senhas seguras e aleatórias

Opção de personalização (letras maiúsculas, minúsculas, números e símbolos)

Interface intuitiva e fácil de usar

## 🚀 Tecnologias Utilizadas

HTML

CSS

JavaScript

## 📦 Instalação

Clone o repositório:

git clone https://github.com/Andre-StudioNerd/GeradorSenha.git

Navegue até o diretório do projeto:

cd GeradorSenha

Abra o arquivo index.html no seu navegador.

## 📚 Como Usar

Abra o arquivo index.html em qualquer navegador.

Selecione as opções desejadas (letras maiúsculas, minúsculas, números e símbolos).

Clique no botão "Gerar Senha".

A senha gerada será exibida na tela.
